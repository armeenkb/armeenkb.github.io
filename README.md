# Armeen Kapadia — Portfolio

A responsive, dependency-free personal portfolio website.

## Run locally

```bash
python3 -m http.server 8000 --directory /root/portfolio
```

Open `http://localhost:8000`.

## Customize

- Replace the introductory copy in `index.html` with your preferred biography.
- Replace the three placeholder project cards with real case studies.
- Add an email address or resume link to the contact section when ready.
